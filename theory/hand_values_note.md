Geometry: flat circular spiral, N = 10, d_out = 100 mm, wire_d = 0.7 mm, pitch = 1.0 mm.
Turn radii r_i = d_out/2 - wire_d/2 - i*pitch = 49.65 ... 40.65 mm; d_in (inner edge) = 80.6 mm,

## Self-inductance: the methods

| Method | L [uH] | vs filament sum |
|---|---|---|
| Filament sum: sum mu0 a_i [ln(8a_i/r_w) - 2] + sum_{i!=j} M(a_i, a_j, 0) | 17.13 | reference |
| Mohan current sheet (circular: c1=1.00, c2=2.46, c3=0, c4=0.20) | 17.78 | +3.8 % |
| Modified Wheeler, octagonal (K1=2.25, K2=3.55) — circle approximation | 18.48 | +7.9 % |
| Modified Wheeler, square (K1=2.34, K2=2.75) — not applicable, for reference | 20.50 | +19.7 % |

- **Filament sum** treats each turn as a thin circular loop. Each loop's own inductance uses the
  round-wire formula; the coupling between turns uses the exact coaxial-loop (elliptic) formula with
  axial spacing 0. Its only approximations are that every turn is treated as a closed circle (the spiral
  is not actually closed) and that current is spread uniformly over the wire, so skin and proximity
  effects at 500 kHz are ignored. It is used as the reference L1 = L2 for k.
- **Mohan** replaces the turns by a uniform current sheet. It agrees with the filament sum to 3.8 %,
  which is within the 2–8 % accuracy Mohan et al. quote for these formulas.
- **Modified Wheeler**: Mohan et al. (1999) give no circular coefficients for this formula. The values
  K1 = 2.34, K2 = 2.75 (labelled "circular" in an earlier version of CONVENTIONS.md, now corrected) are for a **square** spiral.
  A square of side d encloses 4/pi ≈ 1.27 times the area of a circle of diameter d, which explains the ~20 %
  overshoot. The octagonal coefficients, the closest polygon to a circle, give 18.48 uH (+7.9 %).
  Mohan vs octagonal Wheeler differ by 4.0 %. **Conclusion: use the filament sum, cross-checked by Mohan
  (3.8 %); octagonal Wheeler is a rougher check.**

## Validation
- M < sqrt(L1 L2) at every distance (max k = 0.513); k decreases strictly with d.
- Single loop pair (a = b = 49.65 mm), exact vs dipole: dipole differs by +12 % at d = 5a, +3.0 % at d = 10a,
  +0.75 % at d = 20a and +0.12 % at d = 50a, so the two converge as d grows.
- Local log-log slope of M(d): −2.14 (8→10 cm), −2.72 (10→50 cm), −2.87 (20→50 cm), −2.97 (50→100 cm).
  The slope approaches −3 only once d is several coil radii (a ≈ 5 cm). At the test distances
  (d ≤ 10 cm ≈ 2a) the coils are in the near field and M falls more slowly than 1/d^3, so the dipole
  law should not be applied there.
